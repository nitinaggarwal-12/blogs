## Page 1 — Blog 1 (`WS1`): Reference Architecture Taxonomy & 5-Hop Governance Baseline

- **Executive Thesis**: Isolation in a multi-tenant agentic AI platform is a per-tenant tier decision, not a single platform-wide compromise—decoupling an **80% reusable 5-Hop Cryptographic Context Chain** ([`core-cymbal-agent/runtime_pipeline.py`](../core-cymbal-agent/runtime_pipeline.py)) from the **20% perimeter delta** across Pooled (`Pattern A`), Sovereign Silos (`Pattern B`), and Dynamic Hybrid (`Pattern C`).
- **5-Hop Baseline**: Hop 1 OBO + RFC 9449 DPoP + Cloud KMS `EC-P256` ([`hop1_edge_identity_pep.py`](../core-cymbal-agent/governance/hop1_edge_identity_pep.py)) → Hop 2 ARD Catalog & ADK Callback PDP ([`hop2_registry_pdp_callbacks.py`](../core-cymbal-agent/governance/hop2_registry_pdp_callbacks.py)) → Hop 3 `L1–L5` Memory Bank, Valkey Bulkheads & `90%` Prefix Cache ([`hop3_compute_finops_bulkhead.py`](../core-cymbal-agent/governance/hop3_compute_finops_bulkhead.py)) → Hop 4 Model Armor, Semantic NLCs & SDP Redaction ([`hop4_model_armor_guardrails.py`](../core-cymbal-agent/governance/hop4_model_armor_guardrails.py)) → Hop 5 DPoP 3LO Broker, AlloyDB RLS & BigQuery OTel ([`hop5_data_rls_and_otel.py`](../core-cymbal-agent/governance/hop5_data_rls_and_otel.py)).
