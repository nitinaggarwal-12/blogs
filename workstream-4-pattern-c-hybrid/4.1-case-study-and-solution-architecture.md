# Workstream 4.1: Case Study & Solution Architecture — Dynamic Hybrid (Pattern C)

> **Workstream**: Workstream 4 — Hybrid Architecture (Pattern C) [Weeks 7–10 • Milestone 3]  
> **Scenario**: Cymbal operates a unified control plane with intelligent tier routing—serving **RetailStream Corp** on the shared pooled runtime while connecting **FinVault Bank** to dedicated data/tool spokes via **Private Service Connect (PSC)** and supporting **live zero-downtime tier upgrades**.

---

## 1. Why Tiered B2B SaaS Platforms Converge on Pattern C (Dynamic Hybrid)

Most high-growth B2B SaaS platforms serve both SMB/Mid-Market customers (**Standard Tier**) and Fortune 500 regulated enterprises (**Enterprise Tier**) from a single product offering:

* **Standard Tier (`RetailStream Corp`)**: Needs instant self-service onboarding and lowest unit COGS via the **Shared Pooled Runtime** (`ContextCacheConfig` 90% COGS savings, `4,000` thinking cap, shared AlloyDB RLS).
* **Enterprise Tier (`FinVault Bank`)**: Requires Cymbal's unified SaaS control plane and UX, but demands that all private agents (`Agent Alpha`), MCP connectors, and customer data remain inside a dedicated, CMEK-encrypted **VPC-SC Spoke Project** linked via **Private Service Connect (PSC)**.
* **Live Tier Upgrades (`Standard -> Enterprise`)**: When a Standard-tier customer like **RetailStream Corp** signs an Enterprise expansion contract, Cymbal must promote them from the Shared Pool to a Dedicated PSC Spoke **with zero downtime and zero lost sessions**.

## 3. The 3-Phase Zero-Downtime Tenant Tier Migration Protocol

When promoting a tenant (e.g., `retailstream`) from `PATTERN_C_HYBRID_POOL` (Standard) to `PATTERN_C_HYBRID_PSC_SPOKE` (Enterprise):

1. **Phase 1 — Provision Spoke & Shadow State Replication (`SHADOW_SYNC`)**:
   * Terraform provisions the dedicated spoke project (`cymbal-retailstream-spoke-prod`), Cloud KMS CMEK key, VPC-SC perimeter, and Private Service Connect (`PSC`) producer `ServiceAttachment`.
   * The Migration Controller streams the tenant's AlloyDB RLS rows (`WHERE tenant_id = 'retailstream'`) and 5-Level Memory Bank entries (`retailstream:*`) into the dedicated CMEK spoke while the Pooled runtime continues serving live traffic.
2. **Phase 2 — Atomic Control-Plane Cutover (`ATOMIC_CUTOVER`)**:
   * Once replication lag reaches `0 ms` and PSC endpoint health checks pass (`PSC_CONNECTION_ACCEPTED`), the Migration Controller performs a single atomic transaction in Firestore updating `tenant_routing_table['retailstream']`:
     * `topology`: `PATTERN_C_HYBRID_PSC_SPOKE`
     * `tier`: `ENTERPRISE`
     * `thinking_token_budget`: `4000` $\rightarrow$ `8000`
     * `psc_service_attachment`: `projects/cymbal-retailstream-spoke-prod/regions/us-central1/serviceAttachments/retailstream-agent-spoke-psc`
3. **Phase 3 — In-Flight Session Drain & Pooled Cleanup (`DRAIN_AND_VERIFY`)**:
   * Any in-flight turn already executing on the Pooled runtime finishes normally; all subsequent turns within the same conversation session seamlessly route over the PSC endpoint to the new Sovereign Spoke with **zero HTTP 5xx errors and zero dropped context**.
