# Workstream 3.2: Setup Multi-Project Silo Demo & Cloud KMS CMEK Keys (Pattern B)

> **Workstream**: Workstream 3 — Siloed Architecture (Pattern B)  
> **Scope**: Provisioning isolated tenant projects (`cymbal-finvault-silo-prod`, `cymbal-retailstream-silo-prod`), Access Context Manager VPC-SC Perimeters, IAM Principal Access Boundaries (PAB), and Cloud KMS Customer-Managed Encryption Keys (CMEK).

---

## 1. Provision Dedicated Tenant Silo Projects

```bash
export ORG_ID="123456789012"
export BILLING_ACCOUNT="01ABCD-23EFGH-45IJKL"
export REGION="us-central1"
export FINVAULT_PROJECT="cymbal-finvault-silo-prod"
export RETAILSTREAM_PROJECT="cymbal-retailstream-silo-prod"

for PROJ in "${FINVAULT_PROJECT}" "${RETAILSTREAM_PROJECT}"; do
  gcloud projects create "${PROJ}" --organization="${ORG_ID}"
  gcloud beta billing projects link "${PROJ}" --billing-account="${BILLING_ACCOUNT}"
  gcloud services enable \
    aiplatform.googleapis.com \
    discoveryengine.googleapis.com \
    modelarmor.googleapis.com \
    container.googleapis.com \
    cloudkms.googleapis.com \
    alloydb.googleapis.com \
    accesscontextmanager.googleapis.com \
    --project="${PROJ}"
done
```

---

## 2. Create Per-Tenant Cloud KMS Key Rings & CMEK Keys

```bash
# FinVault Bank CMEK Key Ring & CryptoKey
gcloud kms keyrings create finvault-kr \
  --location="${REGION}" \
  --project="${FINVAULT_PROJECT}"

gcloud kms keys create agent-memory-cmek \
  --location="${REGION}" \
  --keyring=finvault-kr \
  --purpose=encryption \
  --rotation-period="7776000s" \
  --project="${FINVAULT_PROJECT}"

# Grant GEAP / Vertex AI Service Agent permission to use the CMEK key
PROJECT_NUMBER=$(gcloud projects describe "${FINVAULT_PROJECT}" --format="value(projectNumber)")
gcloud kms keys add-iam-policy-binding agent-memory-cmek \
  --location="${REGION}" \
  --keyring=finvault-kr \
  --member="serviceAccount:service-${PROJECT_NUMBER}@gcp-sa-aiplatform.iam.gserviceaccount.com" \
  --role="roles/cloudkms.cryptoKeyEncrypterDecrypter" \
  --project="${FINVAULT_PROJECT}"
```

---

## 3. Bind IAM Principal Access Boundary (PAB) Policy

```bash
cat << EOF > /tmp/finvault_pab_policy.json
{
  "displayName": "finvault-sovereign-pab-policy",
  "details": {
    "rules": [
      {
        "description": "Restrict FinVault Agent Runtime & Principals strictly to FinVault Silo Project",
        "resources": [
          "//cloudresourcemanager.googleapis.com/projects/${FINVAULT_PROJECT}"
        ],
        "effect": "ALLOW"
      }
    ]
  }
}
EOF

gcloud iam principal-access-boundary-policies create finvault-sovereign-pab \
  --organization="${ORG_ID}" \
  --location=global \
  --file=/tmp/finvault_pab_policy.json
```
