## 1. Executive Objective of Product Alignment

The current Cloud Architecture Center guide ([Multi-tenant agentic AI system](https://docs.cloud.google.com/architecture/multi-tenant-agentic-ai-system)) documents a **single-enterprise, multi-business-unit** topology where each internal division receives its own GCP project.

However, our field engagements with B2B SaaS ISVs and large enterprises show that **90%+ of B2B SaaS providers** cannot deploy a dedicated GCP project for every $500/month Standard-tier customer due to project quota ceilings, control-plane sprawl, and baseline infrastructure COGS. Conversely, their Fortune 500 financial and healthcare customers demand physical/cryptographic isolation.

This review pack aligns Product Engineering around the **5-Hop Cryptographic Context Chain** across **Pooled (Pattern A)**, **Siloed (Pattern B)**, and **Hybrid (Pattern C)** topologies.

## 3. Deep-Dive Architecture Questions for Product Engineering Sign-Off

### 3.1 GEAP Agent Runtime & ADK 2.0 Team
1. **Immutable Session Context (`temp:tenant_id`)**:
   * *Design*: In Pattern A (Pooled), Hop 1 mints a signed `CryptographicContext` and injects `temp:tenant_id` as an immutable session variable inside the ADK `InvocationContext`.
   * *Sign-Off Request*: Confirm that LLM tool-call arguments or sub-agent transfers (`transfer_to_agent`) cannot overwrite `temp:` prefixed state keys injected by the runner.
2. **Hot-Swappable Model Garden Routing (`Agent Alpha`)**:
   * *Design*: FinVault Bank provisions a private `Agent Alpha` via REST API / `agents-cli` configured to run **Claude 3.7 Sonnet on Vertex AI Model Garden**, while Cymbal's shared agent runs **Gemini 2.5 Pro**.
   * *Sign-Off Request*: Confirm unified ADK `thinking_budget` and OpenTelemetry token accounting parity across Gemini 2.5 Pro and Model Garden partner models.

### 3.2 GCP Agent Identity (Auth Manager) & MCP Team
1. **Zero Google Footprint Tenants (`RetailStream Corp`)**:
   * *Design*: RetailStream authenticates 100% via **Microsoft Entra ID** and uses SharePoint & ServiceNow MCP servers. When a RetailStream engineer triggers an incident workflow requiring ServiceNow write access without a cached token, ADK pauses the turn and emits an interactive 3LO OAuth consent challenge.
   * *Sign-Off Request*: Confirm Auth Manager's external OIDC federation supports Entra ID v2.0 endpoints with DPoP binding (`rfc9449`) without requiring a Google Workspace shadow account.

### 3.3 Cloud Networking, VPC-SC & Security Team
1. **Pattern B (VPC-SC + CMEK Revocation Kill-Switch)**:
   * *Design*: In Sovereign Silos, revoking a tenant's Cloud KMS CMEK key version must immediately halt GEAP Memory Bank reads, AlloyDB queries, and Vertex AI context caches within the tenant perimeter.
   * *Sign-Off Request*: Confirm SLA for CMEK key revocation propagation across GEAP Agent Runtime memory stores (`<= 60 seconds`).
2. **Pattern C (Private Service Connect Spokes)**:
   * *Design*: In Hybrid mode, the shared control-plane router reaches FinVault's dedicated MCP and data spoke over **Private Service Connect (PSC) Service Attachments** without VPC peering CIDR overlap.
   * *Sign-Off Request*: Confirm VPC-SC ingress/egress policy syntax for allowing the central GEAP Routing Hub service account to traverse PSC into a tenant's VPC-SC perimeter while preserving PAB enforcement.
